# Python - Exercícios e Estudos

Repositório com exercícios feitos originalmente durante o curso do PET
Informática do CIn/UFPE, que venho revisitando e aprimorando com os
conhecimentos que adquiri desde então. O objetivo é fortalecer a base
teórica e a lógica de programação.

Cada pasta é organizada por tema. Alguns exercícios têm uma versão
"antes" (código feito no curso) e "depois" (versão revisitada). Outros
ainda não foram revisitados e aparecem com uma única versão.

A documentação dos exercícios mais antigos é mais detalhada; conforme o
tempo disponível foi diminuindo, as anotações foram ficando mais curtas.

Tambem estou usando esse repositorio para praticar git/github
